Global Currency Watch 🌍💱
Global Currency Watch is a modern, responsive single-page web application built with React that allows users to monitor real-time foreign exchange rates, perform instant currency conversions, and analyze historical trends.

Powered by the reliable Frankfurter Forex API, this application provides clean, up-to-date financial data with an intuitive and fast user interface.

✨ Features
Real-Time Exchange Rates: Fetch live foreign exchange reference rates directly from the European Central Bank (via Frankfurter API).

Instant Currency Converter: Convert amounts seamlessly between dozens of global currencies with automatic inverse rate calculation.

Historical Trend Analysis: Visual representation of past exchange rate movements to track currency performance over time.

Responsive & Modern UI: Designed with a sleek, clean interface that adapts seamlessly across mobile devices, tablets, and desktops.

Fast & Lightweight: Built using Vite and React for lightning-fast loading speeds and optimal performance.

🛠️ Tech Stack
Frontend Library: React.js (functional components, hooks)

Styling: CSS3 / Modern Styling

API: Frankfurter API (Open-source API for current and historical foreign exchange rates)

Deployment: Netlify (global-currency-watch.netlify.app)
